## Before install

First make sure you have the following tools installed on your machine:

- [Any Nerd-font ](https://www.nerdfonts.com/font-downloads), and set the font for your terminal application to use the installed Nerd-font

:::tip

If you don't install `Nerd font`, wrapper will still work, but the UI may look a bit off. It's recommended to disable the Nerd font option to avoid this issue.

:::

## Installation Scripts

Copy and paste the following one-line command into your machine's terminal.

### Linux / macOS

With `curl`:

```bash
bash -c "$(curl -sLo- https://wrapper.dev/install.sh)"
```

Or with `wget`:

```bash
bash -c "$(wget -qO- https://wrapper.dev/install.sh)"
```

Use `WRAP_INSTALL_VERSION` to specify a version :

```bash
WRAP_INSTALL_VERSION=1.2.1 bash -c "$(curl -sLo- https://wrapper.dev/install.sh)"
```

### Windows

With `powershell`:

```bash
powershell -ExecutionPolicy Bypass -Command "Invoke-Expression ((New-Object System.Net.WebClient).DownloadString('https://wrapper.dev/install.ps1'))"
```

:::note

To uninstall, run the above `powershell` command with the modified URL:

`https://wrapper.dev/uninstall.ps1`

:::

Use `WRAP_INSTALL_VERSION` to specify a version :

```bash
powershell -ExecutionPolicy Bypass -Command "$env:WRAP_INSTALL_VERSION=1.2.1; Invoke-Expression ((New-Object System.Net.WebClient).DownloadString('https://wrapper.dev/install.ps1'))"
```

With [Winget](https://winget.run/):

```powershell
winget install --id beyondmarks.wrapper
```

With [Scoop](https://scoop.sh/):

```bash
scoop install wrapper
```

## Community maintained packages

[![Packaging status](https://repology.org/badge/vertical-allrepos/wrapper.svg)](https://repology.org/project/wrapper/versions)

> Sort by letter

### Arch

###### Builds package from sources

```bash
sudo pacman -S wrapper
```

###### Builds most recent version from GitHub

```bash
yay -S wrapper-git
```

### Homebrew

Install [Homebrew](https://brew.sh/) and then run the following command:

```bash
brew install wrapper
```

### NixOS

###### Install with nix command-line

```bash
nix profile install github:beyondmarks/wrapper#wrapper
```

###### Install with flake

Add wrapper to your flake inputs:

```nix
inputs = {
  wrapper = {
    url = "github:beyondmarks/wrapper";
  };
  # ...
};
```

Then you can add it to your packages:

```nix
let
  system = "x86_64-linux";
in {
  environment.systemPackages = with pkgs; [
    # ...
    inputs.wrapper.packages.${system}.default  ];
}
```

### Pixi

Install [Pixi](https://pixi.sh/latest/) and then run the following command:

```bash
pixi global install wrapper
```

### X-CMD

[x-cmd](https://www.x-cmd.com/) is a **toolbox for Posix Shell**, offering a lightweight package manager built using shell and awk.

```sh
x env use wrapper
```

## Start wrapper

After completing the installation, you can restart the terminal (if necessary).

Run `wrap` to start wrapper

```bash
wrap
```
