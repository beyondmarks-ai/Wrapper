## 安裝前準備

首先，請確認你的電腦已安裝以下工具：

- [任一 Nerd-font](https://www.nerdfonts.com/font-downloads)，並將終端機應用程式的字型設定為已安裝的 Nerd-font

:::tip

如果沒有安裝 `Nerd font`，wrapper 仍然可以運作，但 UI 可能會看起來有點不對。建議停用 Nerd font 選項以避免這個問題。

:::

## 安裝腳本

將以下單行指令複製並貼到電腦的終端機中。

### Linux / macOS

使用 `curl`：

```bash
bash -c "$(curl -sLo- https://wrapper.dev/install.sh)"
```

或使用 `wget`：

```bash
bash -c "$(wget -qO- https://wrapper.dev/install.sh)"
```

使用 `WRAP_INSTALL_VERSION` 指定版本：

```bash
WRAP_INSTALL_VERSION=1.2.1 bash -c "$(curl -sLo- https://wrapper.dev/install.sh)"
```

### Windows

使用 `powershell`：

```bash
powershell -ExecutionPolicy Bypass -Command "Invoke-Expression ((New-Object System.Net.WebClient).DownloadString('https://wrapper.dev/install.ps1'))"
```

:::note

若要解除安裝，請將上述 `powershell` 指令中的 URL 改成：

`https://wrapper.dev/uninstall.ps1`

:::

使用 `WRAP_INSTALL_VERSION` 指定版本：

```bash
powershell -ExecutionPolicy Bypass -Command "$env:WRAP_INSTALL_VERSION=1.2.1; Invoke-Expression ((New-Object System.Net.WebClient).DownloadString('https://wrapper.dev/install.ps1'))"
```

使用 [Winget](https://winget.run/)：

```powershell
winget install --id beyondmarks.wrapper
```

使用 [Scoop](https://scoop.sh/)：

```bash
scoop install wrapper
```

## 社群維護的套件

[![Packaging status](https://repology.org/badge/vertical-allrepos/wrapper.svg)](https://repology.org/project/wrapper/versions)

> 依字母排序

### Arch

###### 從原始碼建置套件

```bash
sudo pacman -S wrapper
```

###### 從 GitHub 建置最新版本

```bash
yay -S wrapper-git
```

### Homebrew

安裝 [Homebrew](https://brew.sh/)，然後執行以下指令：

```bash
brew install wrapper
```

### NixOS

###### 使用 nix 命令列安裝

```bash
nix profile install github:beyondmarks/wrapper#wrapper
```

###### 使用 flake 安裝

將 wrapper 加入你的 flake inputs：

```nix
inputs = {
  wrapper = {
    url = "github:beyondmarks/wrapper";
  };
  # ...
};
```

接著可以將它加入 packages：

```nix
let
  system = "x86_64-linux";
in {
  environment.systemPackages = with pkgs; [
    # ...
    inputs.wrapper.packages.${system}.default  ];
}
```

### Pixi

安裝 [Pixi](https://pixi.sh/latest/)，然後執行以下指令：

```bash
pixi global install wrapper
```

### X-CMD

[x-cmd](https://www.x-cmd.com/) 是一個 **Posix Shell 工具箱**，提供以 shell 和 awk 建構的輕量套件管理器。

```sh
x env use wrapper
```

## 啟動 wrapper

安裝完成後，你可以視需要重新啟動終端機。

執行 `wrap` 來啟動 wrapper

```bash
wrap
```
