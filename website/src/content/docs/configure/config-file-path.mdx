## Directories

#### Config directory

|         Linux         |                   macOS                   |          Windows           |
| :-------------------: | :---------------------------------------: | :------------------------: |
| `~/.config/wrapper` | `~/Library/Application Support/wrapper` | `%LOCALAPPDATA%/wrapper` |

#### Theme directory

|            Linux            |                      macOS                      |             Windows              |
| :-------------------------: | :---------------------------------------------: | :------------------------------: |
| `~/.config/wrapper/theme` | `~/Library/Application Support/wrapper/theme` | `%LOCALAPPDATA%/wrapper/theme` |

#### Data directory

|           Linux            |                   macOS                    |          Windows           |
| :------------------------: | :----------------------------------------: | :------------------------: |
| `~/.local/share/wrapper` | `~/Library/Application Support/wrapper/` | `%LOCALAPPDATA%/wrapper` |

### Changing Config File Path

You can use the `-c` or `--config-file` flag to specify a different path for the `config.toml` file:

```bash
wrap -c /path/to/your/config.toml
```

You can use the `--hotkey-file` flag to specify a different path for the `hotkey.toml` file:

```bash
wrap --hotkey-file /path/to/your/hotkey.toml
```

#### Log directory

|           Linux            |                   macOS                   |          Windows           |
| :------------------------: | :---------------------------------------: | :------------------------: |
| `~/.local/state/wrapper` | `~/Library/Application Support/wrapper` | `%LOCALAPPDATA%/wrapper` |
